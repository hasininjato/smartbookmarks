# SmartBookmarks

Signets sémantiques pour VS Code qui suivent le code même après refactoring.

## Fonctionnalités
- 🔖 Signets attachés aux fonctions/classes, pas aux numéros de ligne
- 🔄 Suivi automatique après renommage/déplacement
- 🏷️ Tags et notes enrichies
- ⚠️ Détection des signets orphelins
- 🧭 Navigation F2 / Shift+F2

## Raccourcis
| Action | Raccourci |
|--------|-----------|
| Toggle signet | `Ctrl+Shift+B` |
| Panneau | `Ctrl+Shift+L` |
| Signet suivant | `F2` |
| Signet précédent | `Shift+F2` |

## Installation dev
```bash
cd smartbookmarks
npm install
code .
